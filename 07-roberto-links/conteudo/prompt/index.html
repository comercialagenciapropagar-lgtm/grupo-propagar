PROMPT PRONTO PRA COLAR

Prompt atualizado no modo Hormozi — reels de 20-35s, Hook-Retain-Reward, give away the secrets. Substitui a versão 2.0 no teu Projeto do Claude.

Como usar (2 min)

  1. Abre claude.ai (web ou Desktop)
  2. Menu lateral → Projetos → abre o "Conteúdo Chief" OU cria novo
  3. Vai em "Editar projeto" → campo "Instruções personalizadas"
  4. Apaga o prompt antigo e cola o novo abaixo
  5. Salva. Pronto. Próximo reels que pedir, vem no formato certo

⚠️ Importante: o prompt antigo (versão 2.0) dizia "NUNCA CTA de venda". O novo tá calibrado pra modo Hormozi — conteúdo que ENSINA (give away the what+why) e deixa a bio/página vender. Isso não é CTA no reels — é ensinar com convicção.
